# 📱 Dịch Phụ Đề Game — Điện thoại Android

Chơi PS5 trên TV, điện thoại tự **dịch phụ đề Anh → Việt**, hiện chữ và **đọc giọng Việt ngay trên TV**. Không cần máy tính.

## ⬇️ Tải về (luôn là bản mới nhất)
**[Bấm vào đây để tải DichPhuDeGame_Android.apk](https://github.com/HoangTran4869/DichPhuDeGame-Android/releases/latest/download/DichPhuDeGame_Android.apk)**

Tải xong mở file để cài. Cài đè lên bản cũ được, không mất cài đặt. Các bản cũ xem ở mục [Releases](https://github.com/HoangTran4869/DichPhuDeGame-Android/releases).

## 🛠 Cần chuẩn bị
- Điện thoại Android + TV Android / Google TV (ứng dụng **Dịch Game TV**, tải bằng ứng dụng **Downloader** mã **1314378**) hoặc TV LG
- **3 mã Gemini** (mỗi mã ở 1 dự án khác nhau) + **2 mã Groq** (tạo ở 2 tài khoản Google khác nhau) — miễn phí, ứng dụng có hướng dẫn từng bước
- Nên dùng 1 tài khoản PSN phụ cho điện thoại (điện thoại chỉ "xem ké" hình để dịch, Bạn vẫn chơi trên TV)
